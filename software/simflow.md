# About SimFlow (OpenFOAM GUI)

**SimFlow** provides a modern, intuitive graphical user interface for **OpenFOAM**, the industry-standard open-source Computational Fluid Dynamics (CFD) toolbox.

## Key Capabilities for Hydraulic Engineers
- **interFoam Solver:** Solves the 3D Reynolds-Averaged Navier-Stokes (RANS) equations for two incompressible, isothermal, immiscible fluids using the **Volume of Fluid (VOF)** method to capture free surface dynamics.
- **Turbulence Models:** Supports $k-\epsilon$, $k-\omega$ SST, and LES for resolving boundary layer detachment and turbulent vortices behind bridge piers.
- **snappyHexMesh:** Generates high-quality body-fitted hexahedral meshes with prism boundary layers for resolving wall shear stress $\tau_w$.
