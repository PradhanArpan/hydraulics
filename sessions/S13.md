> [!note] Core Concept
> A channel section is defined as **most economical** (or **hydraulically most efficient**) when it conveys the maximum discharge $Q$ for a given cross-sectional area $A$, roughness $n$, and bed slope $S_0$. From Manning's formula, this corresponds directly to minimizing the wetted perimeter $P$ for a given area $A$.

## 1. Most Economical Rectangular Section
Let $A = b y$, so $P = b + 2y = \frac{A}{y} + 2y$.
Setting $\frac{dP}{dy} = 0$:
$$-\frac{A}{y^2} + 2 = 0 \implies A = 2y^2 \implies b y = 2y^2 \implies b = 2y$$
Hydraulic radius:
$$R = \frac{A}{P} = \frac{2y^2}{4y} = \frac{y}{2}$$
**Rule:** Width is twice the depth ($b = 2y$), and hydraulic radius equals half the depth ($R = y/2$).

## 2. Most Economical Trapezoidal Section (Half-Hexagon)
For a trapezoidal section with side slope $1\text{V}:z\text{H}$:
- Condition for optimal depth: $R = \frac{y}{2}$
- Condition for side slope: $z = \frac{1}{\sqrt{3}} = \cot(60^\circ) = 0.5774$
- Top width: $T = 2 \times \text{sloping side length} = \frac{4}{\sqrt{3}}y$
- Bed width: $b = \frac{2}{\sqrt{3}}y$
**Rule:** The most efficient trapezoidal section is a **half-hexagon** inscribed in a semicircle of radius $y$.

## 3. Most Economical Triangular Section
Vertex angle is $90^\circ$, with side slopes $z = 1$ ($45^\circ$ to vertical):
$$R = \frac{y}{2\sqrt{2}} = 0.354 y$$

### Example 13.1: Design of Most Economical Trapezoidal Canal
**Problem:** Design a hydraulically most efficient trapezoidal canal lined with smooth concrete ($n = 0.014$) to convey $Q = 20.0 \text{ m}^3/\text{s}$ on a bed slope $S_0 = 1 / 2000$.

**Solution:**
1. **Best Trapezoidal Geometry (Half-Hexagon):**
   - Side slope: $z = 1/\sqrt{3} \approx 0.5774$
   - Bottom width: $b = \frac{2}{\sqrt{3}}y = 1.1547 y$
   - Area: $A = (b + z y) y = (1.1547 + 0.5774) y^2 = \sqrt{3} y^2 = 1.7321 y^2$
   - Hydraulic radius: $R = \frac{y}{2} = 0.50 y$
2. **Apply Manning's Discharge Formula:**
   $$Q = \frac{1}{n} A R^{2/3} S_0^{1/2}$$
   $$20.0 = \frac{1}{0.014} (1.7321 y^2) (0.50 y)^{2/3} \left(\frac{1}{2000}\right)^{1/2}$$
   $$20.0 = 71.429 \times 1.7321 \times 0.62996 \times 0.02236 \times y^{8/3}$$
   $$20.0 = 1.7417 \times y^{8/3}$$
   $$y^{8/3} = \frac{20.0}{1.7417} = 11.483 \implies y = (11.483)^{3/8} = (11.483)^{0.375} = 2.502 \text{ m}$$
3. **Dimensions:**
   - Water depth: $y = 2.50 \text{ m}$
   - Bottom width: $b = 1.1547 \times 2.502 = 2.89 \text{ m}$
   - Flow Area: $A = 1.7321 \times (2.502)^2 = 10.84 \text{ m}^2$
   - Mean Velocity: $V = Q / A = 20.0 / 10.84 = 1.845 \text{ m/s}$

### Key Takeaways
- Most economical section minimizes wetted perimeter $P$ for given flow area $A$.
- Rectangular: $b = 2y, R = y/2$.
- Trapezoidal: Half-hexagon, $z = 1/\sqrt{3}, b = \frac{2}{\sqrt{3}}y, R = y/2$.
- Triangular: $90^\circ$ vertex ($z=1$), $R = y / (2\sqrt{2})$.
