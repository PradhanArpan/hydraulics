> [!note] Core Concept
> In open channel design, the normal depth $y_0$ represents the steady water depth under uniform flow conditions. Because Manning's equation is non-linear and implicit in depth for trapezoidal and circular channels, engineers employ **iterative numerical methods (such as Newton-Raphson)** or design aids to solve it.

## 1. The Normal Depth Equation
From Manning's equation:
$$A R^{2/3} = \frac{n Q}{\sqrt{S_0}}$$
The left-hand side is termed the **section factor for uniform flow** $K_n(y) = A(y) [R(y)]^{2/3}$, which is a monotonic increasing function of water depth $y$.

## 2. Newton-Raphson Iterative Formulation
Define the residual function:
$$f(y) = A R^{2/3} - \frac{n Q}{\sqrt{S_0}} = 0$$
Using the chain rule, its derivative is:
$$f'(y) = \frac{d}{dy}(A R^{2/3}) = R^{2/3} T + \frac{2}{3} A R^{-1/3} \left(\frac{P T - A \frac{dP}{dy}}{P^2}\right)$$
The Newton-Raphson update step is:
$$y_{k+1} = y_k - \frac{f(y_k)}{f'(y_k)}$$
Typically, 3 to 4 iterations achieve convergence to within $10^{-5} \text{ m}$.

### Example 14.1: Newton-Raphson Solution of Normal Depth
**Problem:** A trapezoidal canal has bed width $b = 5.0 \text{ m}$, side slope $z = 2.0$, bed slope $S_0 = 0.0008$, and $n = 0.025$. It conveys $Q = 25.0 \text{ m}^3/\text{s}$. Compute the normal depth $y_0$ to 3 decimal places using Newton-Raphson iteration.

**Solution:**
Target section factor:
$$K_n = \frac{n Q}{\sqrt{S_0}} = \frac{0.025 \times 25.0}{\sqrt{0.0008}} = \frac{0.625}{0.028284} = 22.097$$

**Iteration 1:** Initial guess $y_1 = 1.50 \text{ m}$:
- $A_1 = (5.0 + 2 \times 1.5) \times 1.5 = 12.00 \text{ m}^2$
- $P_1 = 5.0 + 2(1.5)\sqrt{1 + 4} = 5.0 + 3.0 \times 2.2361 = 11.708 \text{ m}$
- $R_1 = 12.00 / 11.708 = 1.025 \text{ m}$
- $f(y_1) = 12.00 \times (1.025)^{2/3} - 22.097 = 12.00 \times 1.0165 - 22.097 = 12.198 - 22.097 = -9.899$
- Derivative approximation $f'(y_1) \approx 15.6$
$$y_2 = 1.50 - \frac{-9.899}{15.6} = 2.13 \text{ m}$$

**Iteration 2:** $y_2 = 2.00 \text{ m}$:
- $A_2 = (5.0 + 4.0) \times 2.0 = 18.00 \text{ m}^2$
- $P_2 = 5.0 + 4(2.2361) = 13.944 \text{ m}$
- $R_2 = 18.00 / 13.944 = 1.291 \text{ m}$
- $f(y_2) = 18.00 \times (1.291)^{2/3} - 22.097 = 18.00 \times 1.1855 - 22.097 = 21.339 - 22.097 = -0.758$
Updating with $f'(2.0) \approx 19.8$:
$$y_3 = 2.00 - \frac{-0.758}{19.8} = 2.038 \text{ m}$$

**Iteration 3:** $y_3 = 2.038 \text{ m}$:
- $A_3 = 18.50 \text{ m}^2, P_3 = 14.11 \text{ m}, R_3 = 1.311 \text{ m}$
- $f(y_3) = 18.50 \times (1.311)^{2/3} - 22.097 = 22.099 - 22.097 = +0.002 \approx 0$
Convergence achieved! **Normal depth $y_0 = 2.04 \text{ m}$**.

### Key Takeaways

- Non-linear equation solved using iterative Newton-Raphson or spreadsheet solvers.
